# Contributing

Thanks for helping future NY agents pass.

**Accuracy comes first.** If you think something is wrong or out of date, open an issue with a link to the official source (dos.ny.gov, the statute, or the regulation). Please don't correct facts from memory or from a prep book alone.

**Adding questions**
- Write original questions. Don't copy from exams, courses or books.
- Four choices, one clearly correct answer. No "all/none of the above", because choices are shuffled.
- The explanation should say *why*, and cite the rule where there is one (e.g., "RPL §443", "19 NYCRR 175.25").
- Keep to the official 77-hour syllabus topics.

**Before you open a pull request**
```bash
node tests/validate.mjs
```
